# Icon Library — _TBD_

Local source of truth for icon names. Pick icons from this list by name when designing; never invent icon names or fetch the full icon library from Figma at runtime.

Populated from the DS's icon export. If the DS has an "Icons" page in Figma, run a one-time export (the format is a flat list of icon names grouped by category) and paste it here.

---

_TBD — list empty. To populate, export icon names from the DS Figma file's Icons page in this shape:_

```markdown
## <Category name> (count)

- `<icon-name-01>`
- `<icon-name-02>`
- ...
```

Categories typically include: AI / Agents, Arrows / Chevrons, Charts, Communication, Development, Files, Finance, General UI, Images, Layout, Maps, Media, Security, Status / Alerts, Time, Users, Weather. Names follow the convention `<noun>-<variant>-<modifier>` (e.g. `arrow-left`, `check-circle`, `settings-01`).
